# 通知简化与中文提示

按用户最新反馈，本轮有意与 Android 的常驻通知能力区分，不增加后台监控，也不开发小组件。

## 修改

- 使用中通知只显示设备和“请在应用内查看或结束用水”，不显示分钟/秒，不再按分钟重复更新。
- 删除通知上的结束用水按钮，旧版停止 action 也不再接受；保留点击通知尝试打开原订单。使用结束和自动关停等已有通知不变。
- 移除测试通知入口及发送实现，清理旧测试通知和旧计时通知。
- 使用状态开关说明不再承诺显示已用时间。
- 网络三种请求入口统一输出简短中文；超时、断网、安全连接、未知英文错误分别转换。服务端中文原因保留，英文原因使用中文兜底。原始错误仍写日志。
- 同步检查账号操作、云端开关阀、蓝牙连接、设备详情、使用码及背景操作，避免直接展示系统英文异常。
- 短信修改密码允许编辑预填手机号，参考 Android UserScreen.ChangePasswordDialog：验证码发往填写的号码；密码修改请求仍使用现有账号认证字段，不擅自修改协议或切换账号。

## 验证

- 新增安全连接、未知英文异常、中文业务原因和英文业务原因回归；生产 GET/POST/JSON 的断网回归同时检查中文文案。
- 统一通过 GitHub Actions 执行测试并 Archive，版本保持 3.1.0 (18)。不修改用户原有差异文档。
- 真机验收：使用中通知没有计时及结束按钮；结束通知保留；无测试入口；断网开阀中文；短信手机号可编辑。
- 后续新功能主要为小组件。真实旧设备、多设备隔离、断连结算及异常恢复仍需真机验收，不能称为已全部验证。
