# iOS 小组件试验版

## 安卓依据

- widget/WidgetRenderer.kt：LoggedOut/NoDevice/Idle/Running；进行中设备不受寝室筛选隐藏；上次消费按设备读取；附近和账单为缓存而非实时扫描。
- widget/WidgetActions.kt：设备控制、附近、账单三个页面；选用与开阀分离。
- widget/LinYuWidgetProvider.kt：正在操作/结果未知，不把请求失败当成开关成功。
- res/layout/widget_linyu_1x1.xml、widget_linyu_2x2.xml、widget_linyu_2x4.xml：开关、竖向面板、侧栏三页布局。
- res/drawable/widget_glass.xml、widget_inset.xml：深色玻璃、白色高光与边线、内嵌面板。

## 已实现及平台差异（不能称为完全相同）

| 内容 | iOS 实现 |
|---|---|
| 三种布局 | 开关、设备面板、多功能；iOS 小/中/大尺寸适配，没有 Android 的真正 1x1 尺寸 |
| 三页切换 | iOS 17 App Intent 在组件内切换设备/附近/账单 |
| 设备选用 | 组件内选中已查台账的缓存设备，不开阀；真正控制前重新查台账。不同于安卓选用时立即联网验证 |
| 多实例 | 四个可配置的独立设置槽；相同槽共享页和选中设备。不是安卓按 widgetId 自动独立 |
| 控制 | 链接唤起主应用，执行实际开/关阀；复用 ShowerFlow、CloudShower、BleSession，不另外复制协议。与安卓后台服务直接执行不同 |
| 蓝牙 | 主应用扫描目标设备后执行；找不到提示，不误操作当前的其他设备 |
| 安全 | 随机按钮令牌、账号、设备、订单、开始时间校验；账号变化清缓存；忙时禁止控制；旧按钮不可重复申请费率 |
| 计时 | 开始时间由系统动态显示，不代表持续监控设备。应用外被关闭仍需再次同步确认 |
| 数据 | 账号隔离 App Group 展示快照。只存设备和账单展示，不共享登录令牌/手机号/密码 |
| 刷新 | 应用变化请求刷新，系统调度；无后台常驻扫描/监控/定时关阀 |

## 安装要求

- 主应用 3.1.0 (18)，iOS 16+；小组件扩展 iOS 17+。
- 直接用 SideStore 安装 IPA，必须保留 LinYuWidgets 扩展，并为主应用和扩展签署相同 App Group（group.com.hualala.linyu）。
- 未签名 Archive 只能证明扩展被打包，不证明 SideStore 的签名后应用组可用。若组件提示“请保留小组件扩展和共享权限”，需检查签名，不能当作已验证兼容。
- 不使用 LiveContainer 作为原生组件验收环境。

## 验证

- CI：原回归 + WidgetRegression，校验旧按钮、跨账号、新旧订单、寝室筛选、序列化和控制身份。
- Archive：校验 PlugIns/LinYuWidgets.appex 可执行文件、扩展类型和版本。
- 模拟器：固定假数据的闲置/使用中/附近/账单布局截图；不进行真实登录和水控。
- 真机：扩展是否出现在添加列表、App Group 同步、选用不扣款、云端及蓝牙开关、多设备隔离、旧按钮拒绝、结束后消费更新、退出账号清空。

## 未达成项

安卓后台开关阀方式、任意实例自动独立设置、壁纸透射效果无法在此实现中声称一致；目前为真实可操作的前台水控入口版。完整硬件验收仍待用户测试，不称“完全一样”。
