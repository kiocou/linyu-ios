# 真机反馈与通知对齐

基线3155376；保留3.1.0（18）和看教程，未改Android代码。

## 界面与使用码

- 导航栏恢复之前的底部22点布局，移除上批额外安全区偏移和外层GeometryReader。
- 账号管理/重新领取标题独立居中，箭头靠右，不再将标题和箭头一起居中。
- 对照Android UseCodeSection实际LaunchedEffect(Unit)：允许领取时打开弹窗自动生成首个候选。文件头部注释与实际代码不一致，以代码为准；次数耗尽后不打开生成界面，也不再请求候选。
- 服务端返回remainTimes为0后禁用换码；当前有效的最后一个候选仍能领取。退出弹窗再次打开时仅提示次数已用完。次数记录按账号和当天保存，跨日失效；服务端仍是最终权限依据。
- Android现有源码仅按resetAvailability处理当天已领取，不明确阻止20次后的重新打开；次数耗尽保护是本次用户明确要求的补充，不冒称安卓已有实现。
- 修改密码显示当前手机号，模式切换移至新密码/确认密码下方，使用安卓“直接修改密码/短信验证修改密码”文案；取消本地6位密码长度限制，只检查非空及两次一致。
- 验证码发到当前绑定号；保留只读手机号，不复制安卓“可编辑验证码接收号但重置请求仍使用账号认证手机号”的不一致。用户未要求更换重置目标账号。

## 通知分类

| 卡片开关 | 对应行为 |
|---|---|
| 总开关 | 请求系统权限；关闭清理应用通知；权限拒绝时提供系统设置入口 |
| 用水状态通知 | 开始/恢复后显示计时快照，前台按分钟更新；可回使用页或点击结束用水，沿用订单身份校验 |
| 使用结束通知 | 真实关闭后显示用时/金额及关阀失败原因，点结束通知去账单 |
| 自动关停提醒 | 已确认的自动结束事件提示，点通知去账单；不按预设时间虚构设备已关闭 |
| 横幅提醒 | 接入开阀失败、设备占用以及自动结束/关阀异常事件；关闭时使用被动通知，无提示音 |

设置变更会移除不再启用的分类通知，并同步当前活跃订单。结束和自动结束开关独立。计时更新、补齐金额均静默，避免每分钟弹横幅。

Android依据：utils/Notifier.kt、ui/UserSettingsCards相关通知卡片、ShowerWatchService及MainViewModel事件调用。

## iOS边界

普通通知没有安卓前台服务的常驻秒表能力，本实现是最近更新的已用时长快照，不宣称后台每秒刷新。App挂起/终止后不能保证及时检测设备结束；回前台核对后才通知。通知显示仍受系统授权、专注模式、摘要等设置影响。

持续锁屏计时需要另做ActivityKit/Widget扩展；后台结果实时推送还需要相应服务端/APNs能力，本轮未新增。参考Apple UserNotifications授权与ActivityKit文档：

- https://developer.apple.com/documentation/UserNotifications/asking-permission-to-use-notifications
- https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities
