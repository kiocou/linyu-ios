# 2026-10-26 批次一：金额、蓝牙字段、登录与个人资料

基线 iOS `7135cb8`，Android `ff5f8be`。本轮不修改 Android，不调整 3.1.0（18），不修改“看教程”，不合并主分支，不使用子代理。

## 本批修改

1. 钱包刷新只使用元单位的 `money`；不再把 `accountRealMoney`（厘）当成元。心跳原本已使用正确字段，无需重复修改。
2. 蓝牙费率及上传表单统一 randomNumber 小写；类型缺失默认值对齐 Android 的 0/0。短帧随机数保持两字节，不能补宽；protocolType 保持设备值。
3. 将既有状态帧解析从 CoreBluetooth 会话中提取为纯函数，生产会话仍调用同一实现；测试覆盖短帧、长帧、未知长度、错误标记、MAC 和字段位置。
4. 验证码发送失败撤销倒计时，离开页面取消倒计时与发送任务；使用截止时间防止后台暂停造成倒计时漂移。切换模式清空密码和验证码；保留用户要求的 Keychain 记住密码功能。
5. 登录网络错误提供中文提示；改密码、换手机号成功反馈分别使用“密码已修改”“手机号已更换”。
6. 个人资料从账号接口、绑定卡接口、校园接口补齐姓名/学号。新资料非空字段优先，补充来源只填空字段；不以某个接口空值清空已有资料。
7. 个人资料展示缓存按学校+账号归属保存，冷启动先展示后刷新；退出时清理。旧请求写回前检查所属账号和取消状态。此防护仅覆盖资料，不宣称整个水控任务跨账号隔离已完成。

## 与 Android 的对应

- `MainViewModel.refreshWallet`：money 元单位。
- `BleShowerController`：rateOrder/upload 字段大小写与类型默认值。
- `DeviceQueryState`：28 与 ≥31 字节布局。
- `LoginViewModel`：失败撤销验证码倒计时、模式切换清输入、网络错误提示。
- `MainViewModel.loadAccountInfo/applyIdentity/loadCampusBalance`：身份多个来源、内存与持久化同步。iOS 将来源按“账号→绑定卡→校园”顺序补空，避免异步来源相互覆盖。

## 验证与交付边界

整批提交后统一通过 GitHub Actions 运行回归检查并构建 IPA；CI 结果以实际运行记录为准。
离线检查不调用真实账号或水控接口。UI 行为、Keychain 与学校蓝牙设备仍须手机验收。

手机验收：

- 首页/钱包余额与官方对照；有一卡通时仍保留一卡通优先。
- 断网获取验证码后立即恢复可重试；切模式不保留另一模式的密码/验证码。
- 改密码/换号成功提示、保存密码回填。
- 资料缺姓名/学号的账号能否由兜底补齐；冷启动及刷新失败保留缓存；退出换号不串资料。
- 蓝牙设备开关水并导出日志，核对字段与实际结算；本次不改 GATT 时序与重连等待。

另行排期：台账第二候选及连接映射、全链路会话隔离、账单磁盘缓存、通知补全、导航栏安全区和细节验收。
